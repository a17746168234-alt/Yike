# 更新记录

## 1.2.5

- “OCR / 框选”弹出菜单复用主界面的深浅色、圆角、阴影、悬停色与图标设计，不再显示突兀的系统白色菜单。
- 开始下一次翻译时自动停止并清理上一段暂停的朗读，隐藏“继续 / 停止”按钮并恢复初始朗读界面。
- 保持公共赠送额度优先、个人 DeepL 密钥额度作为安全后备的翻译顺序。

## 1.2.4

- 恢复“账号与安全”页面，支持邮箱验证码注册、邮箱密码登录、额度刷新与退出登录。
- 登录会话通过 Windows DPAPI 加密保存在当前用户目录；密码和邮箱验证码不写入本机文件。
- 注册并登录后优先使用 Yike 公共 DeepL 体验额度；公共额度不可用或当前语言不受支持时，安全回退到个人 DeepL 密钥。
- 公共翻译按服务端限制分批请求，支持中文、英语、日语和韩语，并在翻译后同步剩余额度。
- “账号与安全”新增昵称与头像修改；资料按邮箱区分并通过 Windows DPAPI 加密保存在本机，不上传服务器。
- 设置窗口直接复用主界面的浅色/深色语义色板，消除相同主题下的色差。
- 主窗口的窗口控制改为与设置窗口相同的左上角红、黄、绿控制点。

## 1.2.3

- 修复检查更新只读取本地文件而误报最新版的问题，改为查询 GitHub 的 Windows 稳定版，排除 macOS、草稿、预发布和未完成上传的安装包。
- 更新对话框显示实际安装版本和最新发布版本；支持取消下载，校验大小和 SHA-256 后安装并重新启动，保留设置与历史。
- Windows 安装登记版本从实际程序读取，避免版本号散落在 UI 和安装器中。
- 设置已打开时，DeepL 帮助等入口正确切换页面；各窗口标题区按钮不再误触发拖动。
- 权限页可刷新检测快捷键、麦克风、Whisper、Windows 语音组件和 OCR 语言；快捷键页支持重新注册。
- 朗读设置中的暂停与停止按实际播放状态启用；修正空格语音输入与托盘退出说明。

## 1.2.2

- 划词翻译小窗右上角新增关闭按钮。
- 点击标题区按钮图标时不会触发窗口拖动，窄窗口下副标题自动省略。

## 1.2.1

- 修复离线语音识别输出在管道缓冲中等待，导致短句不及时显示的问题。
- 缩小实时识别的音频上下文，停止时保留有界的最后一句识别时间；未识别到文字时给出提示。
- 麦克风就绪后更新监听状态；缩短 Windows 识别的句末等待。
- 朗读首段生成后立即播放，后续段落同时生成，保留完整文本、音色、语速和暂停/停止行为。
- 在线朗读首段并行尝试代理与直连，后续段落优先使用已成功的连接方式。

## 仓库整理

- 当前源码设置界面已移除“账号与安全”页面。
