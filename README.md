## 原有功能

- Apple 系统本机翻译与 DeepL 高质量翻译引擎
- 图片 OCR 翻译与语音输入
- `Shift + Command + F` 划词翻译浮窗
- 在线神经语音朗读，可切换女声和男声，默认 -6% 语速
- 翻译完成后自动预生成译文音频，点击朗读时优先播放缓存
- 在线朗读音频缓存上限约 40 MB；自动语音输入另需下载约 148 MB 的本地识别模型

## 安装

## ⚠️ Windows 用户必读：安装包安全提示

`Yike-Setup.exe` **未使用商业代码签名证书**，因此 Windows 与浏览器会给出以下提示：

- 浏览器：**"通常不会下载 Yike-Setup.exe"**
- 首次运行：**"Windows 已保护你的电脑"**

这些是 Windows 基于**文件信誉**的自动判断，属于未签名软件的常见提示，**不等于检测到恶意代码**。本项目为个人开发的早期开源项目（无商业签名预算），请知悉后自行决定是否安装。

### 继续安装的操作步骤

| 出现的提示 | 处理方式 |
| --- | --- |
| 浏览器下载拦截 | 点击地址栏右侧 **「···」→「保留」** |
| 运行时 "Windows 已保护你的电脑" | 点击 **「更多信息」→「仍要运行」** |
| 文件被 Defender 拦截或删除 | **Windows 安全中心 → 病毒和威胁防护 → 保护历史记录** → 找到该文件 → **「允许在设备上」** |
| 文件属性显示"来自其他计算机" | 右键安装包 → **属性** → 勾选 **「解除锁定」** → 确定 |

批量解锁（PowerShell）：

```powershell
Unblock-File -Path "$env:USERPROFILE\Downloads\Yike-Setup.exe"

打开 `outputs/Yike-macOS-arm64.dmg`，将「Yike」拖入 Applications。

当前安装包为 **1.6（Build 69），Apple Silicon / arm64**。Apple 翻译需要 **macOS 15 或以上**，每台 Mac 首次使用需联网确认并下载对应语言包；安装包不包含语言包或 DeepL 密钥。本应用的 Apple 翻译不支持 Windows。个人 DeepL 需要用户自行设置 API Free 密钥；公共体验可在设置的“账号与安全”注册领取额度，服务开启状态以页面提示为准。

翻译失败后，在右侧“原因 / 解决方法”处查看提示，再选择重试、设置密钥或切换引擎。无法确定的系统错误会明确标注未知原因并提供错误代码，不会将所有失败误报为断网。

## Build 61 交互更新

- 保存或更新 DeepL 密钥后，在主窗口及设置页显示保存成功反馈；只确认本机保存，密钥是否有效由实际 API 请求判断。
- 自动检测语音模式使用本地 Whisper base 多语言模型，首次需确认下载约 148MB；录音结束后识别中文、英文、日文或韩文。手动选语言仍使用系统实时识别。
- 录音时底部工具栏切换为实际麦克风音量驱动的波形，支持完成录音与取消处理。单次录音最多 60 秒，清晰语音后静音约 3.5 秒结束。
- 右侧文字译文可直接输入、粘贴、删除、换行和撤销；编辑译文会停止旧译文朗读，复制使用修改后的内容。图片译文仍通过图片工具编辑。
- 模型优先从 Hugging Face 下载，失败时尝试 hf-mirror.com 备用源；两者下载后均校验相同的大小与 SHA-256。录音只在本地暂存，识别或取消后清除；自动语音模式不上传录音。

## Build 63 下载与界面更新

- 修正语音模型下载失败后的重试入口；显示实际下载 MB 进度，官方源失败后自动尝试备用源，错误提示包含网络/代理、超时或 HTTP 状态及解决方法。网络可达性仍取决于每台电脑的环境。
- 录音中按 Return 结束录音；处理中再次按 Return 不会取消或翻译。识别完成后可检查文字，再点击开始翻译。左右输入框均支持此操作，正常编辑译文时 Return 仍换行。
- 开始翻译按钮的蓝色略加深，空输入时保持可辨认的文字和浅蓝边框；交换语言图标和玻璃底框更淡、阴影更轻。
- 两侧空状态提示统一字体和对齐，右侧简化为“译文显示在这”。

## Build 68 个人资料与引擎标识

- 账号与安全支持自定义用户名及头像；用户名最多 6 个中文或 12 个英文字母，混合输入时中文占两位。
- 主页左上角显示头像和用户名，点击直接打开账号与安全；账号卡片第二行显示邮箱。
- 头像可从 PNG、JPEG、HEIC 图片选择，居中裁切压缩后圆形显示，可恢复默认。用户名和头像按邮箱分别保存在本机，不跨设备同步。
- 公共 DeepL 使用 Yike 菜单栏图标，Apple 使用电脑图标，个人 DeepL 使用 DeepL 标识；统一黑白与尺寸，公共说明简化为“由Yike服务器交由DeepL处理”。
- 验证：编译、安装包及应用签名校验通过；用户已完成本机体验测试。

## Build 69 自动更新

- Yike 启动时每天向自己的服务器检查一次新版；“关于与更新”支持随时手动检查。
- 发现新版后由用户选择“暂不更新”或“立即更新”。立即更新会下载 DMG、校验服务器公布的 SHA-256、核对 Bundle ID 和应用签名，再覆盖当前应用并自动重新启动。
- 覆盖前创建临时备份，替换或签名检查失败时恢复当前版本；更新清单不包含账号、邮箱、DeepL 密钥或其他私密配置。

## Build 67 简化账号验证

- 删除登录、注册、找回密码和绑定邮箱中的人机验证，不再打开浏览器。
- 删除验证码卡片、故障排除窗口、浏览器验证页面和服务端校验模块。
- 注册与密码找回继续使用邮箱验证码；密码校验、发信与登录限流、每邮箱一次赠额保持不变。
- 登录注册弹窗收紧高度，设置页仍保持原有大小。旧账号和额度记录保留。

## Build 65 邮箱账号、额度与语音预览

- “账号与安全”保持与其他设置页相同的 860×600 窗口，只显示未登录状态或账号与赠送额度；点击登录后打开独立的登录/注册弹窗，表单等比例对齐，提供密码显隐、红色找回密码入口和蓝色主按钮，支持真实邮箱验证码与找回密码。
- 邮箱验证注册一次赠送 200,000 字符，总池预算 4,000,000 字符，用完即止；旧账号绑定邮箱后补齐总赠额，消费记录保留。
- 引擎分为 Apple 系统翻译、DeepL 高质量翻译（账号额度）、DeepL（个人接入）。顶部统一简写 DeepL；面板以进度条和已用百分比显示当前引擎对应的额度，Apple 不显示用量。
- 自动语音在录音中每约2秒尝试更新文字预览，实际延迟取决于本机推理速度；中英日韩自动识别，结束后做完整校正。录音留在本机，取消后丢弃迟到结果；按回车结束录音后仍可检查文字再翻译。
- 服务器支持最多4个独立官方 API Free密钥，按实际余额与全站预算限制请求，不使用客户端个人密钥。
- **自行部署时需要管理员配置 SMTP 发信服务与公共 DeepL 密钥**。生产配置保存在服务器，不包含在源码或安装包中。配置步骤与Windows接口见 [server/README.md](server/README.md)。

## 构建

构建需要 Xcode 与 CMake（或通过 `YIKE_CMAKE` 指定 CMake 路径）。首次构建会下载固定版本 whisper.cpp 源码并编译静态语音引擎；不会将语音模型打进 DMG。

在项目根目录运行：

```bash
./native/build.sh
```

构建产物：

- `outputs/Yike-macOS-arm64.dmg`（安装包）
