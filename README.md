# Mac翻译

macOS 原生翻译应用，支持中文、英文、日文和韩文。
基于早期 Codex 版「翻译」工程二次开发，Bundle ID 为 `com.yijian.translator.kimi`。

## 相对早期版本的改进

1. **DeepL 密钥真正存入系统钥匙串**（Keychain Services，service `com.yijian.translator.kimi.deepl`），并在首次启动时安全迁移、删除旧版本的本地密钥文件
2. **状态系统重构**：区分成功 / 提示 / 错误三级提示；权限未授予时提供「打开系统设置」按钮直达对应隐私面板（辅助功能 / 语音识别 / 麦克风）
3. **顶部工具栏精简**：仅保留引擎切换与历史记录；外观、划词权限、历史记录开关、完全退出收进「设置」菜单（齿轮图标）；完全退出也可从菜单栏图标操作
4. **外观三态**：跟随系统（默认）/ 浅色 / 深色，旧版手动深浅设置自动迁移
5. **自动检测语言**：主界面源语言新增「自动检测」选项（默认开启），翻译、朗读、语音输入均按检测结果处理
6. **历史记录强化**：新增时间戳、引擎标签、搜索过滤、置顶、记录开关（隐私）；上限 30 条（置顶不占名额）
7. **DeepL 用量展示**：调用 `/v2/usage` 显示本月字符用量与剩余额度，设置页展示进度条，用量超 90% 红色预警
8. **图片翻译第二版**：拖入图片后左右对照显示；Vision OCR 保留文字坐标；译文按原位置绘制；支持自然融入 / 高对比两种效果、点击放大、复制图片和原尺寸 PNG 保存
9. **图片翻译第三版**：智能合并 OCR 段落，复杂背景使用原图邻边纹理重建；可编辑译文文字、位置、尺寸、字号、颜色和对齐，也可删除译文框
10. **图片工具**：原图左上角或右键可随时打开可视化 OCR 编辑器；点击图片中的文字区域即可在原位置直接改字、删字，红色按钮可删除整个区域，不再使用右侧独立文本框
11. **截图与划词隔离**：截图翻译提供 3 秒切换窗口时间并自动隐藏主窗口；划词浮窗使用独立翻译状态，不再显示或覆盖当前图片译文
12. **图片辅助功能**：原图 / 译图滑杆对比、可开关的最近 10 张本机图片历史、复制与原尺寸 PNG 保存
13. 构建开启 `-O` 优化编译
14. **工程稳定性**：钥匙串与翻译核心已从主文件拆分；文字翻译使用请求 ID 拒绝过期结果；加入钥匙串、请求竞态和文本分段自动化测试

## 原有功能

- Apple 系统翻译、DeepL 和 MyMemory 翻译引擎
- 图片 OCR 翻译与语音输入
- `Shift + Command + F` 划词翻译浮窗
- 在线神经语音朗读，可切换女声和男声，默认 -6% 语速
- 翻译完成后自动预生成译文音频，点击朗读时优先播放缓存
- 在线音频小型缓存上限约 40 MB，不下载本地语音模型

## 安装

打开 `outputs/Mac翻译-macOS-arm64.dmg`，将「Mac翻译」拖入 Applications。

## 构建

在项目根目录运行：

```bash
./native/build.sh
```

构建产物：

- `outputs/Mac翻译-macOS-arm64.dmg`（安装包）

## 自动化测试

```bash
./native/tests/run_tests.sh
```

测试覆盖系统钥匙串读写与删除、旧翻译请求失效和长文本分段。
